# Loan Investment Calculator — 产品需求文档（PRD）

> **状态：v2.1 已验收并在 ChatGPT Sites 发布；PocketBay #3128 删除待执行/核实**  
> **已发布版本：v2.1｜规划版本：v2.2（一键优化待开发）｜更新日期：2026-10-16**  
> 唯一产品定义来源：[产品定型稿](../shaping/06-最终定型稿.md)。若 PRD 与定型稿不一致，以定型稿为准，并通过变更记录同步修订。

## 1. 产品概述

Loan Investment Calculator 是面向马来西亚用户的免费、无需注册的纯前端单页 Web 工具。用户输入贷款参数与固定回报投资参数，选择递减余额法或平息法，并评估贷款期限内逐月月供、派息、现金流、可用现金、资金缺口和净资产。货币为 MYR；默认简体中文，可切换英文。

## 2. 目标与非目标

### 2.1 产品目标
- 让用户理解贷款月供、利息、本金与剩余贷款的逐月变化。
- 将实际派息月份与每月还款放在同一时间线上，揭示现金流压力。
- 明确展示初始保留现金、可用现金、累计净现金流及净资产，避免重复计算。
- 支持切换两种贷款算法并导出当前模式完整逐月 CSV。

### 2.2 非目标
- 不提供个性化贷款或投资建议，不保证回报。
- 不模拟证券价格波动、随机回报、复利或派息再投资。
- 不包含 Moomoo 促销锁定/退款模式。
- 不提供账号、保存历史、数据库、后端、第三方 API 或多货币。

## 3. 目标用户与使用流程

目标用户为希望评估“贷款资金投入固定回报投资”情景的普通个人用户。

1. 打开页面，看到默认参数与简体中文界面。
2. 输入贷款金额、期限、贷款利率、投资金额、预期投资回报率和派息频率。
3. 页面即时验证输入并重算。
4. 选择 Reducing Balance 或 Flat Rate（不提供 Compare 模式）。
5. 查看摘要、两类图表和逐月明细。
6. 可切换简体中文或导出 CSV。
7. Reset 或刷新后恢复全部默认值。

## 4. 输入规格

| 字段 | 控件/类型 | 默认值 | 校验与行为 |
|---|---|---:|---|
| Loan Amount (RM) | 数字输入 | 100000 | 必须大于 0 |
| Loan Tenure (months) | 整数输入 | 60 | 1–420 个月 |
| Loan Interest Rate (% p.a.) | 数字输入 | 4 | 必须为非负数 |
| Investment Amount (RM) | 数字输入 | 100000 | 大于 0，且不得超过 Loan Amount |
| Expected Return Rate (% p.a.) | 数字输入 | 6 | 必须为非负数 |
| Payout Frequency | 下拉/选择 | 6 个月 | 仅允许 1、3、6、12 个月 |
| Loan Mode | 分段选择 | Reducing Balance | Reducing Balance / Flat Rate |
| Language | 语言切换 | English | English / 简体中文 |

## 5. 功能需求

### FR-01 页面与布局
- 单页响应式布局；左侧 Loan、Investment 输入组，右侧结果区。
- 结果区包含摘要卡、月度净现金流柱状图、趋势图和逐月表。
- 小屏幕下输入区上下排列；逐月表允许横向滚动。
- 页面不依赖服务端状态，不保存用户输入。

### FR-02 即时校验与自动重算
- 任一输入变化后立即验证并重新计算。
- 贷款金额必须大于 0；期限必须为 1–420 的整数；贷款利率和投资回报率不得为负。
- 投资金额必须大于 0，且不得高于贷款金额。
- 派息频率只允许 1、3、6、12。
- 校验失败时显示对应字段错误，并隐藏或标记当前结果为无效；不得把旧结果当作当前结果。
- 语言切换不触发不同的计算结果，只重绘界面文案。

### FR-03 贷款计算引擎
**Reducing Balance**
- 月利率 r = 年利率 / 12。
- r > 0 时，月供 = P × r / (1 − (1 + r)^(-n))。
- r = 0 时，月供 = P / n。
- 每月利息按期初剩余贷款余额计算；本金 = 当月付款 − 利息。
- 最后一期调整付款以将余额收口至 RM0.00。

**Flat Rate**
- 总利息 = P × 年利率 × n / 12。
- 每期本金 = P / n；每期利息 = 总利息 / n。
- 每月付款 = 本金 + 利息；最后一期调整以将贷款余额收口至 RM0.00。

**精度要求**
- 使用货币精度 RM0.01，显示两位小数。
- 贷款余额、当期利息、付款和本金以分为单位处理；最后一期收口。
- 年利率输入 4 代表 4% p.a.。

### FR-04 投资派息
- 每次派息 = 投资金额 × 年回报率 × 派息频率（月） / 12。
- 仅在第 k 个月且 k 为派息频率的倍数时产生派息；其余月份为 RM0。
- 不复投、不复利；投资本金在整个贷款期间保持不变。
- 不以派息抵销、跳过或推迟当月贷款月供。

### FR-05 现金流与净资产
每个贷款模式分别独立计算：
- 初始保留现金 = 贷款金额 − 投资金额。
- 月度净现金流 = 当月派息 − 当月月供。
- 累计净现金流 = 从第 1 个月到当月的月度净现金流之和。
- 可用现金 = 初始保留现金 + 累计净现金流；可用现金可为负数，负数代表累计资金缺口。
- 净资产 = 投资本金 + 可用现金 − 当月期末剩余贷款。
- 可用现金已包括初始保留现金及累计净现金流，计算净资产时不得再次单独加计这两项。

### FR-06 贷款模式
- 默认 Reducing Balance。
- Flat Rate 只显示平息模式结果。
- 不提供 Compare 同屏比较模式；用户可以手动切换贷款计算方式。
- CSV 仅导出当前选中模式的全部月份。

### FR-07 结果摘要
摘要至少展示：
- 当前模式的月供。
- 总贷款利息。
- 总派息。
- 期末累计净现金流/资金缺口。
- 期末净资产。
摘要仅展示当前选中贷款模式的结果。

### FR-08 图表
- 移除月度净现金流柱状图卡片，但保留逐月明细表中的月度净现金流数据与计算。
- 趋势图：投资本金、期末剩余贷款、累计净现金流。
- 图表随输入和模式变化即时刷新；小屏幕保持可读。
- 图表不改变计算数据，且应有可访问的标题/说明。

### FR-09 逐月明细表
逐月表包含：
- Month（不显示 Compare 模式列）。
- Monthly Payment、Interest、Principal Paid、Remaining Loan。
- Investment Payout、Investment Principal。
- Monthly Net Cash Flow、Cumulative Net Cash Flow、Available Cash、Net Asset。
- 期限最长 420 个月；MVP 一次性渲染所有行，容器横向滚动。
- 逐月明细每个表头文字本身作为 Tooltip 触发区域（不显示 `i` 图标，可键盘聚焦）；采用 shadcn/ui Tooltip 风格：鼠标 hover 或键盘 focus 显示对应中英文公式/字段含义，移开或失焦关闭，支持 Esc 关闭；手机端点按查看、再次点按或点击外部关闭，不改变计算结果。

### FR-10 CSV 导出
- 页面仅在逐月明细区保留一个 CSV 导出按钮，避免重复入口。
- 导出完整逐月数据，金额两位小数，货币单位 MYR。
- CSV 只导出当前选中贷款模式的数据。
- 文件名应包含产品名与导出日期；CSV 表头随当前语言切换。
- 导出内容应与屏幕显示的计算结果一致。

### FR-11 语言切换与 Reset
- 默认简体中文，支持英文。
- 切换语言只改变文案、标签、状态和 CSV 表头，不改变输入数值或计算结果。
- Reset 恢复所有默认值：贷款 RM100,000、60 个月、4% p.a.；投资 RM100,000、6% p.a.、每 6 个月派息；Reducing Balance；简体中文。

### FR-12 首次打开与持久化
- 每次打开或刷新均恢复默认参数。
- 不使用 localStorage、sessionStorage、Cookie、数据库或服务端保存参数。
- 所有计算在浏览器本地完成，不发送用户输入到服务器。


## FR-13 一键优化投资金额（v2.2 已实现，待部署）
- 在投资金额输入框附近新增一个简洁按钮：「一键优化」（英文：Optimize）。不增加额外设置、复杂面板或搜索算法。
- 点击时读取当前有效的贷款金额、期限、利率、所选贷款计算方式（Reducing Balance / Flat Rate）、派息频率（1、3、6、12 个月）；采用当前模式已计算的**首期正常月供**。
- 空窗期月数 = max(派息频率（月）− 1, 0)。
- 空窗期总月供 = 空窗期月数 × 月供。
- **优化投资金额 = 贷款金额 − 空窗期总月供**；金额以 RM0.01 为精度，显示两位小数。应按现有引擎的货币取整规则计算，避免浮点误差。
- 例如贷款 RM100,000，月供 RM1,841.65，每 6 个月派息：空窗期 5 个月，预留 RM9,208.25，优化投资金额 **RM90,791.75**。
- 派息频率为每 1 个月时，空窗期为 0，优化投资金额等于贷款金额。
- 计算出的金额必须符合现有投资金额校验（大于 RM0 且不超过贷款金额）。若计算结果小于或等于 RM0、输入无效或无法计算，保持原投资金额不变，并提供简短明确的中英文提示；不得写入负数或超过贷款额的投资金额。
- 成功时自动将优化金额填入现有 Investment Amount 输入框，并触发原有校验、摘要、趋势图、逐月明细及 CSV 数据重算；不改变贷款金额、年限、利率、模式、派息频率或默认 Reset 行为。
- **功能边界**：该快捷公式只预留首次派息之前的月供，并非全贷款期限的现金流保障或亏损最小化算法；后续可用现金仍可能为负，须保留原有资金缺口呈现及风险免责声明。
