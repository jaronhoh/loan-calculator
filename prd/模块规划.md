# 模块规划

> 依据：[冻结产品定型稿 v2.0](../shaping/06-最终定型稿.md)，冻结日期 2026-10-15。

## 模块拆分

| 模块 ID | 模块名称 | 范围 | 依赖 | 状态 |
|---|---|---|---|---|

## 全局技术约束

- 静态 HTML/CSS/JavaScript，可托管 GitHub Pages。
- 无后端、数据库、账号、第三方 API 或持久化存储。
- 金额单位 MYR，默认英文并支持简体中文。
- 默认参数：Loan RM100,000；60 个月；4% p.a.；Investment RM100,000；Return 6% p.a.；每 6 个月派息。
- 输入变化即时重算；Reset/刷新恢复默认。
- 表格覆盖全部 1–420 个月；小屏幕横向滚动。
- 净资产计算不得重复计入可用现金中的初始保留现金和累计净现金流。

## 实现顺序

1. M1–M2：输入、语言、默认值、验证。
2. M3–M5：贷款、派息、现金流和净资产纯函数及计算测试。
3. M6–M7：模式切换、比较与摘要。
4. M8–M9：图表和逐月表。
5. M10–M11：CSV、响应式、免责声明与端到端验证。
