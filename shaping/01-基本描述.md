# 01 基本描述

## 原始需求

用户最初提出开发 Web Loan Calculator。产品方向随后扩展为 **Loan Investment Calculator**：评估使用贷款资金进行固定回报投资时的月供、派息时间、现金补贴需求和最终净资产。

用户提供的 Moomoo promotion Excel 作为逐月时间线与余额呈现的参考；用户明确选择该 Excel 仅作设计参考，MVP 不增加独立的促销存款锁定计算模式。

## 一句话定位

> 面向马来西亚用户的免费、无需注册的浏览器端贷款投资计算器，帮助用户比较递减余额和平息贷款方式，并逐月评估固定派息投资的现金流、资金缺口和净资产影响。

## 目标用户

- 有意使用贷款资金投资固定回报产品、希望预先估算月供和现金流压力的个人用户。
- 希望比较递减余额与平息算法结果的普通用户。
- 无角色或权限区分，无需登录即可使用。

## 业务目标

- 让用户看清每月贷款月供与实际派息时间的错位。
- 明确显示每月净现金流，以及保留现金是否足以补贴负现金流。
- 避免将已收派息重复计算为投资回报或资产。
- 可导出逐月数据供 Excel 进一步分析。

## 已知约束

- 纯前端静态单页 Web 应用，可由 GitHub Pages 托管。
- 不需要后端、数据库、账号体系或服务端持久化。
- 货币：MYR（马来西亚令吉）。
- 默认语言为英文，可切换简体中文。
- 每次打开页面均恢复默认值，不保存用户上次输入。
- 贷款期限单位为月，最大 420 个月（35 年）。
- 投资金额必须小于或等于贷款金额。
- 投资回报采用固定年回报率假设，不模拟股票价格波动，不复投派息。

## 默认参数

| 参数 | 默认值 |
|---|---:|
| Loan Amount | RM100,000 |
| Investment Amount | RM100,000 |
| Loan Tenure | 60 months |
| Loan Interest Rate | 4% p.a. |
| Expected Investment Return | 6% p.a. |
| Payout Frequency | Every 6 months |
| Loan Mode | Reducing Balance |
| Language | English |
