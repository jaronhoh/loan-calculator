# 01 基本描述

## 原始需求

用户原话："develop loan calculator (web)" —— 开发一个贷款计算器（Web 端）。

目前信息量很少，属于粗略想法阶段，尚未明确贷款类型、目标用户、是否需要账号体系等关键决策点。

## 一句话定位

> 面向所有人的免费、无需注册的 Web 贷款计算器，支持固定利率法与递减余额法两种计算方式，帮助用户快速测算 MYR 贷款的月供与利息。

## 目标用户

- 通用大众（general public），任何有贷款测算需求的访客，无角色/权限区分。

## 约束

- 平台：Web 端，纯前端静态站点，主要展示托管于 GitHub Pages（无后端、无服务端存储能力）。
- 无账号体系、无持久化存储，页面/浏览器关闭后数据全部清空。
- 单一货币/地区：MYR（马来西亚令吉）。
- 需支持两种利息计算方式：固定利率法（Flat/Fixed Interest）、递减余额法（Reducing Balance / Amortizing）。
