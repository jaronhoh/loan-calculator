# 03 范围边界

## 产品形态

纯前端静态网页应用（Single Page App），HTML/CSS/JS（或前端框架均可），无后端服务、无数据库，主要展示托管于 GitHub Pages。

## MVP 范围 — 做

- 输入表单：贷款金额、年利率（默认预填 4%，用户可修改）、贷款期限（年，可选填月）。
- 计算方式切换：固定利率法（Flat/Fixed Interest） / 递减余额法（Reducing Balance / Amortizing），用户手动切换，非并排对比。
- 输出摘要：月供、总利息、总还款额。
- 完整摊还表：每期期数、月供、本金部分、利息部分、剩余本金。
- 输入校验：贷款金额/利率/期限均不允许负数，校验失败时行内提示错误，不计算。
- 金额格式：2 位小数（MYR/sen），向上取整（round up）。
- 英文界面。

## MVP 范围 — 不做

- 账号系统、登录、历史记录保存（浏览器关闭即清空）。
- 多货币/多地区支持（仅 MYR）。
- 多语言界面（仅英文）。
- 对接真实/实时利率数据源或第三方 API。
- 固定利率法与递减余额法结果并排对比展示。
- 后端服务器、数据库、任何形式的服务端持久化。

## 待确认

无。阻塞与非阻塞问题均已在 05-开放问题.md 中解决。

## 假设

- 切换计算方式时，已输入的贷款金额/期限保留，仅重新计算结果，不清空表单（P1，体验细节，工程实现时可调整，不影响核心产品范围）。
- 页面采用响应式设计，桌面与移动浏览器均可正常使用（面向所有人的公开 Web 工具的合理默认，未来如有特殊设备限制需求可再澄清）。
- 期限默认单位为「年」，可选精确到「月」；若用户只填年，月数按 0 计。
- 「向上取整」应用于最终展示的金额（月供/总利息/总还款额/摊还表逐期金额），中间计算精度为工程实现细节，不作为产品决策。

## 技术偏好

- 纯前端实现，适配 GitHub Pages 静态托管（无服务端渲染、无服务端逻辑依赖）。
