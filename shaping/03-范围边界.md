# 03 范围边界

## 产品形态

- 产品类型：纯前端静态单页 Web 应用。
- 运行平台：现代桌面及移动浏览器；可由 GitHub Pages 托管。
- 主要交互：左侧输入区，右侧结果区；输入变化后自动重算。
- 货币：MYR。
- 数据处理：仅在浏览器运行，不上传或持久化用户输入。

## MVP 范围 — 做

| 能力 | 包含行为 | 纳入原因 |
|---|---|---|
| 贷款输入 | Loan Amount、Loan Tenure（月）、Interest Rate (% p.a.) | 核心计算输入 |
| 投资输入 | Investment Amount、Expected Return (% p.a.)、Payout Frequency | 表达贷款资金投入固定回报投资 |
| 贷款模式 | 默认递减余额；可选平息或比较两种模式 | 评估不同计息方法 |
| 派息逻辑 | 每 1、3、6 或 12 个月派息；只在对应月份入账 | 不把现金派息平均摊到每个月 |
| 逐月时间线 | 月供、利息、本金、剩余贷款、派息、月度净现金流、累计现金流、可用现金、净资产 | 展示现金流和债务随时间变化 |
| 现金差额 | 贷款金额减投资金额作为初始保留现金；用于覆盖负现金流；允许余额为负 | 展示实际资金缺口 |
| 最终净资产 | 投资本金 + 可用现金 − 剩余贷款 | 避免派息重复计入资产 |
| 图表 | 月度净现金流柱状图；投资资产、剩余贷款及累计净现金流趋势 | 快速理解逐月变化 |
| 逐月明细 | 大型表格展示每月结果 | 支持逐月核对 |
| CSV | 导出当前模式数据；比较模式同时导出两种贷款算法的逐月数据 | 支持 Excel 分析 |
| 双语 | 英文默认，可切换简体中文 | 满足语言需求 |
| 自动重算 | 任一输入变化后即时更新结果、图表和明细 | 快速进行情景试算 |
| Reset | 一键恢复全部默认参数、默认模式与英文 | 便于重复测试 |
| 校验 | 投资金额不得高于贷款金额；金额、期限和利率需为有效非负值 | 防止不符合资金模型的输入 |

## 默认参数

- 贷款金额：RM100,000。
- 投资金额：RM100,000。
- 贷款期限：60 个月；最大 420 个月。
- 贷款年利率：4%。
- 投资预期年回报率：6%。
- 派息频率：每 6 个月。
- 默认贷款模式：递减余额。
- 默认语言：英文。

## MVP 范围 — 不做

- Moomoo 促销存款锁定/退款专用模式（Excel 仅作为逐月表格设计参考）。
- 股票价格波动、随机回报、Monte Carlo 或收益率变化模拟。
- 派息再投资、复利或派息产生额外投资回报。
- 贷款月供因派息而跳过、延迟或减少。
- 投资金额高于贷款金额的情景；不得额外假设用户投入自有资金。
- 登录、账号、历史记录、浏览器本地持久化、数据库或后端。
- 实时利率、实时投资回报或第三方 API。
- 多货币支持。

## 技术偏好

- 静态 HTML/CSS/JavaScript 或适合静态托管的前端框架。
- 无后端、无数据库、无账号系统。
- 用户输入仅存于当前页面运行状态；每次打开/刷新页面恢复默认值。

## 已确认业务假设

- 固定投资回报率是用户输入的情景假设，不表示实际或保证回报。
- 投资本金保持不变；派息是现金收入，不复投。
- 贷款按月还款，无论派息月份如何都不得跳过月供。
- 初始保留现金 = 贷款金额 − 投资金额。
- 可用现金 = 初始保留现金 + 截至该月累计的月度净现金流；余额可为负数。
- 月度净现金流 = 当月投资派息 − 当月贷款月供。
- 净资产 = 投资本金 + 可用现金 − 当月期末剩余贷款。
- 不应把“初始保留现金”和“累计净现金流”分别重复加到净资产中；可用现金已包含两者。
