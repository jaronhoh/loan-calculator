## 已确认决策

- B1：面向所有人（general public）的自助 Web 工具，任何人都能使用，因此选择 Web 形态。来源：用户 2026-07-16 聊天回复。
- B2：不限定单一贷款类别（不区分房贷/车贷/个人贷），核心差异在于**计算方式**：固定利率法（Flat/Fixed Interest）与递减余额法（Reducing Balance / Amortizing）需分别支持。来源：用户 2026-07-16 聊天回复。
- B3：无需账号体系、无需保存历史，关闭浏览器后数据全部清空（纯前端、无状态）。来源：用户 2026-07-16 聊天回复。
- B4：单一货币/地区，MYR（马来西亚令吉）。来源：用户 2026-07-16 聊天回复。
- B5：主要展示托管于 GitHub Pages（静态站点，纯前端，无后端）。来源：用户 2026-07-16 聊天回复。
- N1：输出结果同时包含摘要数据（月供、总利息、总还款额）与完整摊还表（每期明细）。来源：用户 2026-07-16 聊天回复（采纳推荐方案）。
- N2：不做固定利率法/递减余额法并排对比，由用户通过切换（toggle/tab）选择一种计算方式，查看该方式下的结果。来源：用户 2026-07-16 聊天回复。
- N3：利率为用户输入项，默认预填值为 4%（年利率）；期限单位沿用推荐方案（年，可选月）。来源：用户 2026-07-16 聊天回复。
- N4：仅英文界面，不做多语言。来源：用户 2026-07-16 聊天回复。
- N5：贷款金额、利率、期限均不允许负数（基础合理性校验，不设具体业务上下限）。来源：用户 2026-07-16 聊天回复。
- N6：金额精度为 2 位小数（MYR/sen），舍入规则为「向上取整（round up）」，而非标准四舍五入。来源：用户 2026-07-16 聊天回复。
