# 产品定型稿（Product Shipping Brief）

> 状态：已更新，待用户最终确认冻结。更新日期：2026-10-15。

## 1. 一句话定位

面向马来西亚用户的免费、无需注册的浏览器端贷款投资计算器，用于比较递减余额和平息贷款方式，并逐月评估固定派息投资的现金流、资金缺口与净资产影响。

## 2. 目标用户

- 有意将贷款资金投入固定回报投资、希望评估月供与现金流压力的个人用户。
- 希望比较不同贷款计息方式的普通用户。
- 无角色区分，无需登录。

## 3. 核心场景

- 用户输入贷款金额、贷款期限（月）、贷款年利率、投资金额、投资预期年回报率和派息频率，估算贷款期限内的逐月结果。
- 用户比较递减余额与平息两种方式，理解不同算法对月供、贷款余额和现金流的影响。
- 用户在派息月份收到现金收入；其他月份没有派息，但贷款月供仍照常发生。
- 用户通过初始保留现金补贴负月度净现金流；现金不足后以负数继续显示累计资金缺口。
- 用户导出逐月 CSV，在 Excel 中继续分析。

## 4. 产品形态

- 纯前端静态单页 Web 应用，可由 GitHub Pages 托管。
- MYR；默认英文，可切换简体中文。
- 无后端、数据库、账号体系或服务端持久化。
- 修改输入后自动重算；每次打开/刷新恢复默认参数。

## 5. MVP 范围

**输入与默认值**
- Loan Amount：RM100,000。
- Loan Tenure：60 个月，最大 420 个月。
- Loan Interest Rate：4% p.a.。
- Investment Amount：RM100,000，必须小于或等于 Loan Amount。
- Expected Investment Return：6% p.a.。
- Payout Frequency：每 1、3、6 或 12 个月，默认每 6 个月。
- 默认贷款模式：Reducing Balance；可切换 Flat Rate 或 Compare。
- 默认语言：English；可切换 Simplified Chinese。

**计算与结果**
- 递减余额法与平息法分别计算月供、利息、本金及剩余贷款。
- 投资派息只在设定的实际派息月份发生，按固定年回报率及派息间隔计算。
- 派息作为现金收入，不复投、不产生额外投资回报；投资本金保持不变。
- 月度净现金流 = 当月派息 − 当月贷款月供；负数表示当月需要补钱。
- 初始保留现金 = Loan Amount − Investment Amount。
- 可用现金 = 初始保留现金 + 累计月度净现金流；余额可低于 RM0，以显示资金缺口。
- 逐月净资产 = 投资本金 + 可用现金 − 当月期末剩余贷款。可用现金已包括初始保留现金和累计现金流，禁止重复计算。
- 展示结果摘要、月度净现金流柱状图、投资资产/剩余贷款/累计现金流趋势图和完整逐月明细表。
- 支持 CSV 导出；Compare 模式下同时导出递减余额和平息两种模式的逐月数据。
- Reset 恢复全部默认值、Reducing Balance 模式和英文界面。
- 任何输入变化后自动更新结果、图表和明细。

## 6. 页面与主流程

1. 打开单页 → 默认英文、默认参数、Reducing Balance。
2. 左侧输入区包含 Loan 与 Investment 两组字段；右侧显示结果、图表和逐月表。
3. 修改字段后立即校验并自动重算。
4. 若投资金额高于贷款金额，显示行内错误，不继续计算。
5. 用户切换 Flat Rate 或 Compare，刷新对应计算结果。
6. 用户切换语言，计算结果不变，只切换 UI 文案及 CSV 表头。
7. 用户导出 CSV；比较模式导出两种贷款模式的数据。
8. 用户点击 Reset，恢复默认参数、默认模式和英文。
9. 用户刷新或重新打开页面，恢复默认值；不保存上次输入。

## 7. 数据与权限

**主要输入对象**
- Loan：loanAmount、loanTenureMonths、annualLoanInterestRate。
- Investment：investmentAmount、annualInvestmentReturnRate、payoutFrequencyMonths。
- Preferences：loanMode、language。

**逐月结果对象**
- month、monthlyPayment、interest、principalPaid、outstandingLoan、investmentPayout、investmentPrincipal、monthlyNetCashFlow、cumulativeNetCashFlow、initialRetainedCash、availableCash、netAsset。

**计算口径**
- monthlyNetCashFlow = investmentPayout - monthlyPayment
- initialRetainedCash = loanAmount - investmentAmount
- availableCash = initialRetainedCash + cumulativeNetCashFlow
- netAsset = investmentAmount + availableCash - outstandingLoan

权限：无角色区分，所有访客均可使用，不需登录。

## 8. 暂缓范围

- Moomoo 促销存款锁定/退款专用模式。
- 股票价格波动、随机收益、Monte Carlo 或投资回报率变化模拟。
- 派息再投资、复利或派息产生额外投资回报。
- 投资金额高于贷款金额的情景。
- 登录、账号、历史记录、本地持久化、后端或数据库。
- 实时利率/投资回报数据与第三方 API。
- 多货币支持。

## 9. 已确认决策

- 贷款模式：默认递减余额，支持平息及比较模式。
- 贷款期限使用月，默认 60 个月，最大 420 个月。
- 投资金额不得超过贷款金额。
- 派息为现金收入，不复投；贷款每个月照常还款。
- 贷款与投资金额差额为初始保留现金；负现金流优先消耗保留现金，余额可为负数。
- 月度净现金流仅显示当月派息减月供。
- 净资产 = 投资本金 + 可用现金 − 剩余贷款；可用现金包含初始保留现金及累计净现金流，不重复计数。
- 自动重算、CSV 导出、比较模式双数据导出、英文默认/简体中文切换、Reset。
- 每次打开/刷新恢复默认值，不保存参数。
- Moomoo Excel 只作逐月表格参考，不加入促销模式。
