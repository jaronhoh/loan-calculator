# 产品定型稿（Product Shipping Brief）

> 状态：已冻结（Frozen）。冻结日期：2026-07-16。

## 1. 一句话定位

面向所有人的免费、无需注册的 Web 贷款计算器，支持固定利率法（Flat/Fixed Interest）与递减余额法（Reducing Balance / Amortizing）两种计算方式，帮助用户快速测算 MYR 贷款的月供与利息。

## 2. 目标用户

通用大众（general public），任何有贷款测算需求的访客，无角色/权限区分，无需登录即可使用。

## 3. 核心场景

- 用户拿到贷方报价的固定利率条件，输入金额/利率（默认 4%）/期限，计算实际月供。
- 用户评估递减余额法贷款，查看月供及完整的每期摊还明细，理解利息如何随本金递减变化。
- 用户不愿注册或留下个人数据，打开即用，几秒内拿到结果。
- 用户在两种计算方式间切换（非并排对比），已输入数值保留，结果按新方式重新计算。
- 用户输入负数金额/利率/期限，系统阻止计算并提示错误。

## 4. 产品形态

纯前端静态网页应用（Single Page App），HTML/CSS/JS（或前端框架），无后端服务、无数据库，主要展示托管于 GitHub Pages。

## 5. MVP 范围

**做：**
- 输入表单：贷款金额、年利率（默认预填 4%，可修改）、贷款期限（年，可选填月）。
- 计算方式切换：固定利率法 / 递减余额法，用户手动切换，非并排对比。
- 输出摘要：月供、总利息、总还款额。
- 完整摊还表：逐期期数、月供、本金部分、利息部分、剩余本金。
- 输入校验：金额/利率/期限均不允许负数，校验失败行内提示错误，不计算。
- 金额格式：2 位小数（MYR/sen），向上取整（round up）。
- 英文界面。

## 6. 页面与主流程

单页应用（无多页导航、无账号页、无历史记录页）：

1. 打开页面 → 显示输入表单（金额为空、利率默认 4%、期限为空、计算方式切换）。
2. 用户填写字段 → 系统校验（禁止负数）。
   - 校验失败 → 行内错误提示，不计算。
   - 校验通过 → 计算并展示结果摘要 + 完整摊还表。
3. 用户切换计算方式 → 已输入的金额/期限保留，按新方式重新计算并刷新结果。
4. 用户关闭/刷新浏览器 → 所有输入与结果清空，恢复默认初始状态。

## 7. 数据与权限

- **CalculationInput**：loanAmount、annualInterestRate（默认 4）、tenureYears、tenureMonths（可选，默认 0）、method（fixed | reducing_balance）。
- **CalculationResult**：monthlyPayment、totalInterest、totalRepayment、schedule（每期：periodNumber、payment、principalPortion、interestPortion、remainingBalance）。
- 均仅存于浏览器内存/当前会话，无持久化实体，无用户/账号/历史记录对象。
- 权限：无角色区分，所有访客拥有相同、唯一的使用权限。

## 8. 暂缓范围

- 账号系统、登录、历史记录保存。
- 多货币/多地区支持（仅 MYR）。
- 多语言界面（仅英文）。
- 对接真实/实时利率数据源或第三方 API。
- 固定利率法与递减余额法结果并排对比展示。
- 后端服务器、数据库、任何形式的服务端持久化。

## 9. 已确认决策

- 目标用户为所有人（general public），自助 Web 工具，无角色区分。来源：用户 2026-07-16 聊天回复。
- 不限定单一贷款类别，核心差异在于计算方式：固定利率法与递减余额法需分别支持。来源：用户 2026-07-16 聊天回复。
- 无账号体系、无持久化存储，浏览器关闭后数据全部清空。来源：用户 2026-07-16 聊天回复。
- 货币/地区：MYR。来源：用户 2026-07-16 聊天回复。
- 托管形态：主要展示于 GitHub Pages，纯前端静态站点。来源：用户 2026-07-16 聊天回复。
- 输出包含摘要数据与完整摊还表。来源：用户 2026-07-16 聊天回复（采纳推荐方案）。
- 不做两种计算方式并排对比，由用户切换查看。来源：用户 2026-07-16 聊天回复。
- 利率为用户输入项，默认预填 4%（年利率）。来源：用户 2026-07-16 聊天回复。
- 仅英文界面，不做多语言。来源：用户 2026-07-16 聊天回复。
- 贷款金额/利率/期限均不允许负数。来源：用户 2026-07-16 聊天回复。
- 金额精度 2 位小数，舍入规则为向上取整（round up）。来源：用户 2026-07-16 聊天回复。
